# 講座Skill公開と除去の検証

対象: Issue #1745。公開済みのファイルは不変とし、本文・参照資料のUTF-8サイズとSHA-256を実際の配信バイトから算出する。出典は承認された候補と固定入力から導き、呼び出し元による根拠の省略を拒否する。

ファイル集合を非公開のstaged状態で保存した後、承認ハッシュ・現在の講座構成・全ファイルの存在を再確認して、公開先を同一トランザクションで切り替える。公開後の候補編集を拒否し、取り下げはすべての旧URIにも適用する。

配信時に公開版が依存する所属ID・解析版・画像版を現データと比較する。無関係な動画の追加は旧版を失効させない。一方、根拠動画の除去は定期照合を待たず、一覧・メタ情報・本文・参照資料の取得を拒否する。既に取得済みの内容は回収しない。

PostgreSQLとD1で、入力・知識・候補・公開の共通契約各13ケース、計26ケースが成功。公開前の非公開、二重公開、他利用者の取得拒否、無関係な追加、除去直後の直接URI拒否、承認と公開の間の除去、manifest不一致、取り下げと公開済み候補の編集拒否を含む。

残った知識による候補再構成と公開終了の管理画面は、生成パイプラインと管理画面の統合検証で扱う。本番への配備やMCPクライアントからの検証結果ではない。
