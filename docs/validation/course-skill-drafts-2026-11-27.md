# 講座Skill候補の生成検証

対象: Issue #1744。講座内の支持された知識から、タスク単位の候補と出典ファイルを作る。

計画は知識32項目ずつで行い、既存タスクの識別子を維持する。手順・判断・検証の知識が不足する候補は保留する。視覚依存で確認待ちの知識を根拠から外す。候補の全ブロックに既知のfactIdsを要求し、別のLLM検査で意味の支持関係と条件・例外の抜けをレビューする。自動検査に合格しても人の公開レビューは必要とする。

Markdownはプログラムで生成し、SKILL.mdとreferences/sources.mdを同じ入力から再現できる。候補の保存には現在の所属・解析版とジョブリースを要求する。編集は楽観ロックを使い、根拠とタスク識別子を変更させず、承認を無効化する。

単体5ケースと、PostgreSQL・D1の入力／知識／候補の共通契約各10ケース、計25ケースが成功。API型検査が成功。実モデルの候補品質、長時間ジョブの全段階の自動実行、公開の競合は後続の統合検証で扱う。
