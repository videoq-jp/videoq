# 実モデルによる講座Skill生成の小規模試験

## 検証環境

データは新規の使い捨てローカルD1、教材は実在の講座を使わない合成字幕。モデルはリポジトリの本番設定と同じ`@cf/google/gemma-4-26b-a4b-it`、temperature=0、出力上限4096。Cloudflareの既存Wrangler OAuth認証をメモリ内で利用し、公式のOpenAI互換APIを呼び出す。認証値をコマンド引数・生成物・ログに保存しない。

VideoQアカウントではworkers.devのsubdomain未設定のため、Wranglerのremote binding previewが起動できなかった。アカウント設定を変更せず、モデルAPIの直接呼び出しで接続を確認した。本番DB、R2、動画、公開ルート、schedulerには接続・書き込みを行わない。

## 実行

`apps/api`を作業ディレクトリとして実行する。

```sh
npx tsx scripts/evaluate-course-skills.ts
# 説明の表示だけ。モデルを呼ばない。

npx tsx scripts/evaluate-course-skills.ts --run \
  --account-id <VideoQのaccount ID> \
  --wrangler-auth-file <既存Wrangler設定ファイルのパス> \
  --output <結果JSONの保存先>
```

既存のLLM_API_KEY環境変数を用いる場合、auth-fileは省略できる。最大12回のモデル呼び出しにローカルのAI利用枠を設定し、最大16回の保守実行で停止する。ローカルの再開時刻を強制的に早めるため、経過時間を本番での完了時間やSLAとして扱わない。

結果JSONには固定教材の識別子、モデル、設定、候補、出典、知識、利用枠、匿名cost ledgerを保存する。HTTP失敗は合成入力の診断用としてステータスとproviderのエラーを記録する。実データ用の汎用ロガーではない。生成と意味検査の実モデル呼び出しを含むが、画像読解、実講座の品質、実クライアント接続や実装効果の3条件比較は、この試験だけでは立証しない。

## 発見と修正

- Workers AIのJSON grammar compilerが、同一文字列にpatternと長さ制限を併記したSchemaを400で拒否した。モデルへ渡すSchemaからこの組み合わせだけを解消し、サーバー側の元のZodによる長さ・形式検査は維持した。過大な値を拒否する回帰試験を追加した。
- 初回のタスク計画は実装手順と検証を別々の不完全なタスクへ分割した。公開可能な候補にはならず、知識不足として保留された。
- 「検証方法」をprocedureとして分類するケースがあった。知識抽出の分類定義を明確にし、検証手順をverificationとして扱うようにした。
- タスク計画の構造化出力で、判断・実装手順・検証の出典IDを別々に選ばせるようにした。参照先は各役割で許可された実在のIDに限定する。全役割が入力ページに存在する場合は各役割を必須とし、関連しない場合は候補なしを許す。機械的な参照検査、本文の意味検査、人のレビューを継続する。

修正後、1件の出典付きSkillを生成して意味検査に合格し、レビュー待ちまで到達した。公開はしていない。約270秒、7呼び出し（うち出力上限による失敗3回）を消費した。入力10,415トークン、出力15,346トークンで、公表単価での換算は約0.00565 USD。成功したこの1試行のみの値であり、事前の診断試行、無料枠、税等は含まない。詳細は[生の検証記録](evidence/course-skills-live-generation-2026-11-27.json)と[モデルの公表単価](https://developers.cloudflare.com/workers-ai/models/gemma-4-26b-a4b-it/)を参照。出力上限による失敗が残るため、大規模な処理へ広げる前に安定性と生成量を評価する。実装への効果比較は[統合検証手順](course-skills-integration-2026-11-27.md)に従う。

## 人による確認で残った点

最終候補には、教材に直接は登場しない注文・在庫処理の適用例が追加されていた。元の一般則を応用した説明ではあるが、講師が述べた実例と同一視してはならない。LLMの意味検査でsupported=trueになっても、人による確認を省略できないことを示す。管理画面から適用条件・例外・適用例を修正でき、根拠を確認できない適用例は除いて再検査できるようにした。この候補は自動公開していない。
