# 講座Skillsの知識抽出検証

対象: Issue #1743。固定された生成入力から、字幕に出典を持つ知識を抽出・保存する。

## 実装

字幕はSQLの文字オフセットで最大12,000文字ずつ読み、SRT区間を保持してモデル入力へまとめる。CRLFとUnicodeの境界をまたいでも区間IDと時刻が安定する。LLMの構造化出力に主張・適用条件・例外・対象バージョン・字幕引用を要求する。区間IDの存在と引用の一致はプログラムが検査する。意味の支持関係は後続のSkill検査・レビューと併せて判断する。

画像が必要な主張は一度needs_visual_reviewとして保存する。既存の画像キャッシュから必要な時間帯の最大8枚を読み、画像ID・時刻を指定して追加解釈する。有効な画像IDと直接の観察がある知識を採用し、欠落・不鮮明な内容は保留する。画像抽出は再実行しない。画像バイトを知識キャッシュやSkillへ保存しない。

抽出結果は動画の解析版・所有者・言語・生成方針・モデル・プロンプト・チャンク内容で識別し、完了済みのモデル呼び出しを再利用する。保存と読み取りで有効なジョブリースと現在の講座構成を検査する。動画除去後は保存済み知識もそのジョブから読めない。

モデル呼び出しは一実行の上限を引数で指定し、既存の所有者AI枠を呼び出しごとに予約する。既存のcost ledgerへskill_generationとして利用量を記録する。モデルを呼ぶ前に失敗した場合は予約を返却する。

## 検証

- 5種類のページ幅でCRLF・Unicode・時刻・区間IDが維持される。
- 不正字幕、過大な単一区間、架空の区間ID・引用を拒否する。
- キャッシュからの再開では同じモデル呼び出しを行わない。
- 視覚依存の主張を確認待ちにする。
- PostgreSQLとD1の共通契約で、元字幕の取得、知識の保存・取得、権限拒否、除去後の読み書き拒否を確認した。

字幕・画像の単体9ケースが成功。両DBの共通契約、パイプライン自動実行と管理画面を含む最新の検証は[統合検証](course-skills-integration-2026-11-27.md)を参照。実モデルの課金を伴う品質評価は未実施。字幕の根拠が全くない画像だけの講義は、この字幕起点の抽出経路では対象にならない。
