`io-boundary.mjs` is shared by only these scoped acceptance tools. It rejects group/other-accessible workspace directories, non-regular or foreign-owned input files, input symlinks and oversized input files. Existing output symlinks are replaced as directory entries by atomic rename, never followed. The trusted boundary is the local operator account and owner-only workspace; it is not a defense against arbitrary code already executing as that same user. A crashed process can leave the exclusive lock, deliberately blocking further mutations until the operator verifies the stopped owner before removing it. No automatic stale-lock deletion is added.

Export creates a new snapshot file exclusively rather than truncating an existing snapshot. Repeating export requires an explicitly reviewed new/retired fixture input; the tool no longer silently overwrites prior backup evidence. All generated configuration/log/receipt writes in the driver now use atomic private workspace writes. Trusted repository source/migration files and the user's Wrangler credential cache remain read-only inputs.
